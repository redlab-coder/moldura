# Imagens da apresentação

`banner.svg` e `download.svg` são elementos vetoriais próprios, feitos com a paleta e o símbolo do Moldura.

`workspace.png` e `sheet.png` mostram a interface real do aplicativo. As artes botânicas são conteúdo de demonstração criado para este repositório; não são fotografias de clientes.

Para reproduzir as capturas, execute `python scripts/capture_docs.py` com Playwright e Microsoft Edge disponíveis. O script usa uma instância isolada e encerra somente o servidor que ele iniciou.
