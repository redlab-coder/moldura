# Contribuir

Para relatar um problema, abra uma [issue](https://github.com/redlab-coder/moldura/issues/new/choose) com a versão do aplicativo, os passos para reproduzir e o resultado esperado. Use imagens de demonstração; não publique fotos de clientes ou informações pessoais.

Para propor uma mudança, explique primeiro o problema que ela resolve. O Moldura prioriza uma interface simples, medidas de impressão consistentes e processamento local das fotografias.

Antes de enviar código, consulte o [guia de desenvolvimento](docs/development.md) e execute os testes relacionados à alteração. Mudanças visuais devem incluir uma captura de tela com conteúdo de demonstração.
